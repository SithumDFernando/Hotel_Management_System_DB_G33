# SkyNest brand source files

These PNGs are the original artwork and are **not** served to the browser.

- The canonical mark is the hand-drawn SVG in `frontend/src/assets/skynest-mark.svg`
  (plus `skynest-mark-mono.svg`, a one-colour version that uses `currentColor`).
  Its colours are the spec 11 tokens: circle `paper-200` `#EEEBE3`, bird and waves `tea-900` `#173A2B`.
- The favicons in `frontend/public/` were rendered from that SVG, not from these PNGs
  (the PNGs carry a jagged halo and an off-palette green, ~`#0F4A33`).
- The wordmark is set in Source Serif 4 600 next to the mark (`components/ui/Logo.jsx`);
  the heavy serif in `SkyNest Green Wave Logo (1).png` is not part of the type system.
